# Agent Delegation

Terminal-first orchestration for your installed **OpenCode**, **Codex**, **Claude Code** and **agy** agents, inside a **Codex or Claude Code** host session. Configure your orchestrator, planner, advisor, executor and reviewer models; your existing host plans, delegates, verifies and follows up. CLI execution stays the default; optional Codex App Server, Claude Agent SDK and Antigravity ACP adapters add provider events and active-task controls.

This extends the original agy plugin. Existing `/agy:*` commands and their installer remain available; see [legacy documentation](docs/legacy-agy.md). The repository and local marketplace keep the historical `agy-plugin-cc` name so existing installs keep resolving; the installable plugin and package are `agent-delegation`.

## Why use it

- **The host stays in charge.** Codex or Claude Code owns the conversation, integration and final acceptance. Delegation is bounded help, not a second reasoning harness.
- **Work stays observable.** Every dispatch has a task ID, event stream, pinned context and stable retry identity. `tasks`, `watch` and `wait` work across hosts.
- **Providers are replaceable.** Roles select native agents or external CLIs. A same-provider follow-up keeps its native session; a provider switch builds an explicit portable handoff.
- **Writers are isolated when it matters.** Supervisor mode adds per-step Git worktrees, typed results, independent review and configured checks before central integration.
- **Claims are not evidence.** The parent inspects the diff and runs the checks; advisor or reviewer approval is input, not acceptance.

## Quick start

Requirements: Node.js **22.18+** (or 24+), a supported host, and whichever executor CLIs you intend to use. Authenticate each CLI normally before delegation. Only installed executors you select are required.

From this checkout:

```sh
npm ci
node scripts/dev/install-delegation.mjs codex    # or claude, or both
```

The installer packages a self-contained `plugins/agent-delegation` directory, registers this checkout as a local marketplace and installs the plugin. It does not replace your existing agy plugin or select the host's model. Start a new session after installation.

Configure the project once:

```sh
node scripts/agent-runner.mjs configure --cwd /path/to/project --host codex
```

Use `--host claude` for Claude Code. Setup creates a starter `.agent-delegation.json`, adds an orchestration instruction block to `AGENTS.md` or `CLAUDE.md`, and generates native role definitions. Existing instructions and unrelated agent files are preserved; `--dry-run` previews changes.

Then prompt normally: "Implement this feature" or "Investigate and fix this bug." The host uses configured workers when they help and handles small tasks directly. Automatic delegation depends on the active model and host policy; it is not a deterministic scheduler.

Explicit work:

```sh
# Asynchronous worker; returns a task ID immediately
node scripts/agent-runner.mjs delegate --session-id demo --executor claude --prompt-file task.md --json

# Supervised plan, parallel worktrees, review and verification
node scripts/agent-runner.mjs run --cwd /path/to/project --task-file task.md --approve-all --json
```

To package without installing, or to try a temporary Claude session:

```sh
npm run package
claude --plugin-dir ./plugins/agent-delegation
```

Other local coding harnesses can invoke the runner or load the skill if they support local scripts. Their plugin installation formats are not covered by this release. External CLI jobs do not share the parent's transcript or native agent lifecycle.

## Providers

| Executor | Default CLI route | Rich route | Notes |
| --- | --- | --- | --- |
| Codex | `codex exec --json` | App Server | Structured output, resume, steering and interrupt on App Server. |
| Claude Code | `claude --print --output-format stream-json` | Agent SDK | Structured output, resume, steering, interrupt and an optional Claude `advisor`. |
| OpenCode | `opencode run --format json` | none | Starter executor; no schema-constrained output. |
| agy | headless `stream-json` | Antigravity ACP | Opt-in; consumer-plan policy warning and a separate ACP runtime. |

CLI routes resume through provider session IDs and cancel by terminating the worker process. Rich
routes add protocol-level controls and permission handling. Read
[provider compatibility](docs/provider-compatibility.md) for the full capability matrix, event
contracts and fixture-refresh steps, and [ACP setup](docs/antigravity-acp-setup.md) for the
Antigravity runtime.

## Configure

A typical configuration looks like this; the committed
[example](examples/agent-delegation.json) adds supervisor and monitor roles. The starter generated by
`configure` leaves model names unset so each harness uses its own defaults:

```json
{
  "orchestrator": { "host": "codex", "model": "gpt-6-luna", "effort": "medium" },
  "automation": { "mode": "auto", "maxParallel": 4 },
  "defaultExecutor": "opencode",
  "executors": {
    "opencode": { "model": "opencode/glm-5.3-flash-free" },
    "codex": { "effort": "high" },
    "claude": { "effort": "high" }
  },
  "roles": {
    "planner": { "executor": "codex", "transport": "auto" },
    "advisor": { "executor": "claude", "transport": "auto" },
    "executor": { "executor": "opencode" },
    "reviewer": { "executor": "codex", "transport": "auto", "effort": "low" }
  }
}
```

The orchestrator owns the conversation, integration and completion. Planner, advisor, executor and
reviewer are optional roles, not a fixed sequence. [Configuration](docs/configuration.md) covers
model options, transports, advisor roles, `start`, automation limits, the direct runner and the
OpenCode/agy caveats.

## Permissions and trust

Generic delegation requires explicit `--approve-all` for writes or tool execution; planner,
advisor, explorer, monitor and reviewer roles suppress bypass even when it is supplied.
`supervisor.verifyCommands` are executable project configuration: `run` refuses to start without
`--approve-all` when any are configured, including on resume. Workers are untrusted and their
claims are not acceptance. Read [security and trust boundaries](docs/security.md) before running in
a checkout you did not author.

agy is opt-in because Google's consumer-plan policy does not support wrapping it in third-party
coding agents. Use it only with a Gemini API key or Enterprise login.

## Development

```sh
npm test
npm run check:versions
npm run package
```

The default suite uses fixture executors and recorded provider streams. Set `AGENT_LIVE_TESTS=1`
before `npm test` to include authenticated CLI smoke tests; these make model requests.
`AGENT_LIVE_CODEX_MODEL` and `AGENT_LIVE_CLAUDE_MODEL` select models for those tests without
changing your CLI configuration. Set `AGENT_INSTALL_TESTS=1` to test both installers in temporary
host configuration directories. Packaging copies shared runtime files into the plugin; generated
copies are gitignored and must be rebuilt after source changes.
